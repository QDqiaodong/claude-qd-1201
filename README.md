# 修鞋皮具护理坊（shoe_care）

Spring Boot 3.3 + Vue3(Element Plus) 全栈种子仓，题材为线下修鞋与皮具护理实体店，驼色 #A1887F 主题，左侧分组菜单导航，卡片网格 + 悬浮操作范式。

## 端口
- 前端 8321 / 后端 8421 / MySQL 3621 / Redis 6621（见 `.env`，勿改）

## 4 个业务模块与关系面
1. **皮具台账**（leather_good）：登记待护理/已接的皮具（鞋、包、皮带等）。
   - 关系面：① 品类约束（鞋/包/皮带/箱/其他）；② 状态流转（待接→护理中→待取→已取，已取不可回退）。
2. **护理工单**（care_order）：每张皮具对应护理项目（清洁保养/补色/换底/换跟/缝线）。
   - 关系面：① 未填项目不允许「完成」；② 报价必填且 > 0；③ 须关联已登记皮具。
3. **配件耗材**（part / part_use）：胶水、鞋线、鞋底、五金等库存。
   - 关系面：① 库存为负或低于预警下限时拦截领用；② 领用减库存。
4. **会员与取件**（member / pickup）：会员信息、积分（消费累计）、取件记录。
   - 关系面：① 取件须皮具为「待取」且所有工单已完成；② 积分按消费计算并刷新会员等级。

## 启动
```bash
./start.sh      # docker compose 起前后端 + mysql + redis
./clean.sh     # 收摊并删除匿名卷
```
前端 http://127.0.0.1:8321 ，后端接口前缀 /api。

## 业务规则自检提示
种子数据含异常态用于触发拒绝分支：L3 待取但工单未完（取件拦截）、O2 报价 0（完成拦截）、P1/P3 低于下限（领用拦截）、L4 已取（状态回退拦截）。
